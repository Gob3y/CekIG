# CekIG — Instagram Followers, Unfollowers & Pending Requests Audit

Website audit Instagram 100% lokal di browser (tanpa login, tanpa password, tanpa server) dengan dukungan multibahasa otomatis (**Indonesia** untuk wilayah Indonesia, **English** untuk pengguna internasional).

## Fitur Utama
- **Audit Lengkap**: Tidak Follback, Saling Follow (Mutual), Belum Difollow (Fans), **Pending Follow Requests**, **Baru Di-unfollow**, dan **Whitelist**.
- **Deteksi Bahasa Otomatis (ID / EN)**: Otomatis menyesuaikan bahasa berdasarkan zona waktu / bahasa browser pengguna, lengkap dengan tombol ganti bahasa manual `ID | EN`.
- **Akurasi Tinggi**: Mengabaikan folder Threads/Facebook di dalam ZIP Meta, mendeteksi rentang tanggal ekspor yang tidak cocok (*1 tahun terakhir* vs *Sepanjang waktu*), mendukung skema JSON terbaru (`string_list_data` maupun `label_values`), dan menandai akun yang dihapus (`__deleted__*`).
- **Aksi Massal**: Buka profil massal (5 / 10 / 15 tab), pilih halaman, tandai selesai massal, salin daftar, dan ekspor CSV.
- **Responsif & Nyaman**: Tampilan modern Light/Dark Mode, panduan ekspor, bagian Cara Kerja, FAQ interaktif, dan kartu responsif di mobile.
